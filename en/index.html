01What to hand over

Start with work whose result can be checked.

We do not hand agents just anything. Work comes first when there is a way to tell whether the result is right. Here are three examples.

  • Development

    What the agent does

    Writes a plan, then builds in an environment separate from the original.

    How it is checked

    Checked with tests and on the real screen.

  • QA

    What the agent does

    Runs the tests and plays through the build.

    How it is checked

    Checked against a checklist.

  • Review

    What the agent does

    Reviews changes made by another agent.

    How it is checked

    The evidence for the review is recorded.

QWhat is AX?

AShort for AI transformation. It is more than handing out AI tools: what to delegate, how results are checked, and who is accountable are decided again for working with AI.

02How it works

A person signs off twice. Agents do the rest.

One task moves through six steps. A person signs off at two of them: before the work starts and before it is applied. Try approving the sample below.

Sample task

Step Owner What happens Status
  1. 01 Plan Agent Writes down what will change and how. Queued
  2. 02 Scope sign-off Person Reads the plan and approves the scope. Queued
  3. 03 Build Agent Works in an environment separate from the original. Queued
  4. 04 Verify Agent Checks with tests and on the real screen. Another agent reviews. Queued
  5. 05 Apply sign-off Person Looks at the result and the evidence, then approves applying it. Queued
  6. 06 Record Agent Records what was done and what could not be verified. Queued

QWhat happens when an agent gets it wrong?

AThe flow assumes it can. Work happens in an environment separate from the original, results that fail verification are not applied, and a person signs off before anything is applied.

03What we built

We build it and use it before we recommend it.

Our AI transformation starts with what we have built ourselves: an agentic system for agents to work in, and the products we make with it.

Technology

Agentic System

A system that brings together the agents that take on work, the harness around them, and the points where a person signs off. The six steps above run inside it.

  • Goal Drift Control

    Keeping long-running agents on the original goal

    Keeps the original goal and completion criteria in a ledger while AI works, and checks tool calls and completion claims against approvals and evidence.

  • Recursive Harness Self-Improvement

    RSI at the harness level

    An experiment in which the agent proposes changes to its own harness, with selection and final evaluation kept separate, to see whether real development tasks improve.

  • Spec-Driven Agentic Development

    Software development on an AI-native SDLC

    Connects planning, design, and post-build review through one record. Requirements and scope are written down, and the screens that get built are checked and measured against them.

  • Agentic Game Development

    Game development with agents in the loop

    On every turn of game development, picks the checks that fit the request and the change, and passes the results to the next turn. Compares Unity lighting, inspects and drives the running UI, and captures the screen.

  • Agentic Marketing

    Marketing run with agents

    Plans targeting, positioning, channels, and campaigns, produces copy and content, and tracks posting schedules and results, together with agents.

Products

Made with the agentic system

  • Games

  • Content

QWhat is an agentic system?

AA system built so that AI agents take on work and carry it through. It is made of agents and a harness, which defines what an agent knows, what it may do, the order work moves in, and how results are checked.
